# R01 제작 기준 · clay-v8

사용자가 제공한 8방향·얼굴 확대 시트의 회색 비둘기를 실제 3D 모델로 제작합니다. 현재는 체형과 정적인 깃털 형상·기본색을 함께 대조하는 구간입니다. 시트 원본 파일은 실행 환경과 저장소에 없으며, `profiles.json` 값은 시각 추정값입니다. 픽셀 실측값이나 외형 일치율로 표시하지 않습니다.

- 앞·옆·뒤에서 같은 본체를 사용합니다. Blender +Z 위, -Y 앞, +X 왼쪽, H=1 기준입니다.
- 몸통·목·머리는 연속 단면 로프트이며 정수리는 연속 곡면으로 연결합니다.
- 둥근 아랫배가 다리 위쪽을 덮고, 어깨 외피가 몸통 옆면과 등을 감쌉니다. 그 위에 실제 얇은 겹깃을 배치합니다.
- 기본색/무채색 전환은 같은 GLB의 재질만 바꿉니다. 색을 끄고도 체형·깃 방향·날개 연결을 확인합니다.
- 최종 미세 깃가지·색/광택·리그·7종 자세는 남아 있습니다. 기술 검사 통과는 외형 일치의 합격 판정이 아닙니다.
- 이전 비둘기 모델이나 외부 모델을 불러오지 않습니다.

## 현재 변경

clay-v8은 둥근 정수리를 유지하며 뒤통수·볼·턱의 부피와 눈 위치를 조정했습니다. 부리·납막을 함께 높이고 부리 아래 연결을 채웠습니다. 아랫배는 타원체 곡률로 닫고 넓은 구간에서 본체와 연결합니다. 발 간격·다리 굵기와 접힌 긴깃·꼬리 끝도 줄였습니다.

날개 덮깃과 두 줄 무늬, 긴깃·꼬리깃, 목·가슴의 작은 깃털은 표면을 따라 겹치는 메시입니다. 머리에는 넓은 깃판 대신 가늘고 휘어진 깃결 조각을 낮게 배치합니다. 목은 정점색을 연속 보간해 청록·보라색이 딱딱한 띠처럼 끊기지 않게 구성합니다. 현재 색은 기본 PBR 색이며 최종 광학적 목 광택을 구현한 것으로 표시하지 않습니다.

본체·두상·날개·꼬리 매개변수는 `art/pigeon/profiles.json`, 조형과 내보내기는 `scripts/pigeon-stage1/build.py`, 깃털 배열은 `scripts/pigeon-stage1/plumage.py`에서 수정합니다. [실제 결과와 기록](reviews/clay-v8/README.md)을 기준으로 검토합니다.

## 재생성

Blender 4.x·NumPy·Pillow를 준비하고 프로젝트 루트에서 실행합니다.

```sh
npm run pigeon:probe
npm run pigeon:build
```

기본 빌드는 원본 `art/pigeon/pigeon.blend`, GLB와 manifest, Blender 전신 8방향을 생성합니다. `PIGEON_MODEL_ONLY=1`이면 원본·GLB·생성 기록만 만들고 Blender 전신 캡처는 생략합니다. 이번 clay-v8 원본은 이 옵션으로 생성했으며 전신 비교 자료는 실제 웹 렌더입니다. 과거 캡처는 각 리비전 폴더에 보존합니다.

```sh
npm run build
npm test
npm run source:check
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium node scripts/pigeon-stage1/verify.mjs
```

웹 검증 스크립트는 프로덕션 E2E와 같은 GLB의 기본색 전신 8방향·얼굴 3방향, 무채색 전신 5방향·얼굴 3방향을 촬영합니다. 렌더 기록에는 GLB 해시와 재질 모드가 포함됩니다.

## 이전 체형 이력

clay-v3은 가슴·배, clay-v4~v5는 머리와 얼굴 관계, clay-v6은 몸통의 앞뒤 축·몸통을 감싸는 어깨·접힌 날개와 꼬리 부피를 수정했습니다. clay-v7은 전역 얼굴 면 변형을 제거하고 정수리 연결을 부드럽게 했습니다. [clay-v7 원본과 비교 기록](reviews/clay-v7/README.md)은 해당 커밋에 고정합니다.

Blender Wing Generator 공개 코드의 대상은 Blender 5.2이며 현재 제작 경로에서는 사용하지 않습니다. GitHub 검증 작업은 contents: read 권한으로 결과를 아티팩트에 보관하며 저장소에 자동 커밋하거나 배포하지 않습니다.
