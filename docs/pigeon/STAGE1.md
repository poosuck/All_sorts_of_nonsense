이 문서는 2026-10-24의 **이전 시제품 기록**입니다. 2026-10-25 모델·재질 개선과 비교 화면의 최신 내용은 [모델 개선 v2](MODEL-V2.md)에 있습니다.

기준일: 2026-10-24 (한국 시간). 사용자가 선택한 범위는 **비둘기·공원과 걷기·먹기·날기 검증**입니다. [사용자 제공 명세 원문](pigeon_feeding_spec_v1.0.md)은 변경 없이 보존합니다. 그 문서의 확정 요구사항·설계안·초기 조정값을 서로 구분하며, 명세 전체를 구현한 상태가 아닙니다.

명세 파일 SHA-256: `b4310e0f552bf5165d884448703cf70ceaf26b9afe1fa88fa0530359b483e075`.

## 실행과 관찰

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소에서 홈의 비둘기 카드를 누르거나 `/pigeon`으로 이동합니다.

- 일반 비둘기 / 닭둘기 선택: 선택한 개체의 발밑에 얇은 원을 표시합니다.
- 걷기: 좌우 발을 번갈아 딛고 발을 들며 목과 몸통을 움직입니다.
- 먹기: 살피기 → 목 낮추기 → 세 번 쪼기 → 고개 들기. 부리 끝을 실제 모델 좌표로 확인합니다.
- 날기: 날개 벌리기·퍼덕임·이륙 → 작은 비행 경로 → 발 내리기·착륙 → 휴식. 반복 클립 길이는 7.6 시뮬레이션 초입니다.
- 일시정지 / 재개 / 처음부터. 탭이 숨겨지면 시뮬레이션 시계도 멈추고 복귀 시 누적 시간을 따라잡지 않습니다.
- 다른 비둘기는 배경에서 걷거나 먹는 동작을 반복합니다. 개체끼리의 충돌·경로 회피는 아직 없습니다.

## 자산과 시안 차이

제공된 이미지는 **목표 분위기와 형태의 정적인 시안**입니다. 실제 3D 모델·리깅·음원 파일은 제공되지 않았습니다. 현재 모델과 공원은 Three.js 기본 도형·인스턴싱·코드 생성 텍스처로 직접 제작했습니다. 이미지 배경을 3D처럼 보이도록 움직이는 방식이나 제3자 모델 대체를 사용하지 않았습니다.

- 공원: 포장 바닥, 벤치, 화단·나무, 난간, 강·다리·건물 실루엣, 따뜻한 조명과 그림자.
- 모델: 일반형과 과장되게 둥근 닭둘기, 몸통·가슴·목·머리·부리·주황 홍채·검은 동공·광택점, 날개와 겹친 깃 모양, 꼬리, 붉은 발·발가락.
- 관절: 목을 숙이는 피벗, 양 날개, 발과 정강이. 공중에서도 실제 모델 위치가 바뀝니다.
- 시안 대비 한계: 도형 기반 윤곽이 드러나며 깃털의 부드러움·복잡한 형태, 사실적인 눈의 재질·눈꺼풀, 공원 식생·배경의 밀도, 렌더링 완성도에 차이가 있습니다. 시안 품질 재현 완료로 표시하지 않습니다.
- 외부 자산·네트워크 요청·API 키·새 패키지 추가 없이 실행합니다. 별도 리깅 모델로 교체하려면 원본 파일과 사용 권한을 확인해야 합니다.

## 코드 구조

- `src/views/PigeonView.vue`: Vue 상태·선택·관찰 UI·홈 복귀.
- `src/features/pigeon/scene.js`: 렌더러, 카메라, 6마리 배치, 시계, 가시성, 리사이즈, 오류·자원 정리.
- `pigeon-model.js`: 체형·재질·눈·날개·발 생성, 포즈와 실제 부리/발 좌표 조회.
- `motion.js`: 프레임 주사율과 분리된 시간 기반 동작, 비행 단계, 정지 시계.
- `park.js` / `resources.js`: 공원·고정 장식·텍스처와 공유 GPU 자원 소유.
- `pigeon.css`: 페이지 안에 범위를 제한한 스타일.

푸딩 원본·생성 코드·음원은 수정하지 않습니다. 두 콘텐츠는 별도 경로에서 지연 로딩하며 Three.js 라이브러리 청크만 공유합니다.

## 검증

검증일: 2026-10-24. Node 24.19.0, npm 11.9.0, Chromium 154 headless / SwiftShader. PC 브라우저 자동 검사는 1440×1000, deviceScaleFactor 0.5이며 별도 시각 검토 화면은 1600×1000, deviceScaleFactor 1입니다.

| 검사 | 실제 결과 |
| --- | --- |
| `npm run source:check` | 원본 푸딩 17개 파일과 생성 결과 일치 |
| `npm test` | **14 통과 / 0 실패** — 기존 11개 + 비둘기 3개 |
| 개발 서버 전체 E2E | **11 통과 / 0 실패** — 푸딩/플랫폼 8개 + 비둘기 3개 |
| 프로덕션 dist 전체 E2E | **11 통과 / 0 실패** |
| 마지막 장면 수정 후 프로덕션 비둘기 E2E | **3 통과 / 0 실패** |
| 마지막 수정 후 `npm test`, `npm run build` | 14개 통과, 빌드 성공 |
| 푸딩 원본·생성 엔진·음원 diff | 변경 없음 |

검토 과정에서 포장 바닥이 강 위를 덮는 문제, 비행 중 진행 방향과 바라보는 방향, 포즈 전환, 이탈 시 WebGL 컨텍스트 정리를 보완했습니다. 전체 검사 이후의 최종 수정은 비둘기 모듈에 한정했으며 다시 빌드한 **최종 dist**에서 비둘기 3개 E2E를 재실행했습니다. 단위 검사에는 비행 경로의 접선 방향과 실제 3D 모델의 부리 높이·발 좌표 검사가 포함됩니다.

브라우저에서 확인한 범위:

- 홈 카드 → `/pigeon`, 직접 접속·새로고침·홈 복귀, 이탈 후 재진입과 단일 캔버스.
- 실제 모델의 교대 보행, 부리 끝이 내려갔다 올라오는 식사 클립, 이륙 고도·날개 각도·착륙.
- 일반형과 닭둘기 선택, 동작 전환, 정지 중 프레임·시계·고도 고정, 재개와 초기화.
- 1100px PC 창에서도 주요 조작 버튼 노출과 가로 넘침 없음.
- 기존 푸딩의 변형·복원, 손·양푼·채찍, 맛·설정·리셋, 모바일 누르기, 실제 오디오 출력·중첩·볼륨·음소거·종료 회귀 검사.
- 통과한 브라우저 검사 중 수집한 페이지 예외·error 콘솔 없음.

최종 장면 화면: [공원·먹기](stage1-park.png), [비행](stage1-flight.png). [시각 검토 기록](visual-check.json)은 최종 dist를 따로 열어 실제 모델 좌표와 브라우저 오류·외부 요청을 기록한 자료입니다. 정적인 시안 이미지로 실행 화면을 대체하지 않았습니다.
