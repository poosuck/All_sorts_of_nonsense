# 비둘기 외형 검증실 · 1단계 (2026-10-27)

## 범위

기존 비둘기 v3 모델과 동작, 공원·푸딩 코드는 그대로 두고 별도 URL `/pigeon/model-lab`을 추가합니다. 기존 모델은 직접 확인하는 기준점이며 **시안 재현 완료를 뜻하지 않습니다**.

- 기본 제공 `normal-v3.glb`, `chicken-v3.glb` 로딩
- 외부 GLB 파일 선택·로딩(브라우저 메모리에서만 처리, 별도 서버 업로드 없음)
- Urban Pigeon CC0의 온라인 불러오기 **시도**. 외부 서버 CORS나 링크 변경 시 실패할 수 있어 로컬 GLB 파일 선택을 제공
- 사용자가 가진 공원 목표 이미지를 로컬에서 열어 양쪽에 나란히 표시
- 회전(OrbitControls), 확대, 정면·측면·후면·45° 시점, 빛 강도 및 색감 변경
- 모델 애니메이션 클립 이름 표시·재생
- 메시·삼각형·재질/컬러 텍스처·스킨 메시·애니메이션 수 확인
- 모델 렌더 이미지 PNG 저장

### 모델 출처 및 사용

기존 v3 GLB는 저장소 자체 제작 소스이며 상세 출처는 `docs/pigeon/MODEL-V3.md`. 외부 모델은 **새로 저장소에 복제·커밋하지 않음**. 표시한 CC0 예시는 해당 배포 페이지에서 다운로드 상태·라이선스를 다시 확인해 사용해야 함. 임의 Sketchfab/Fab 에셋을 본인 소유인 것처럼 포함하지 않음.

## 사용

```sh
npm ci
npm run dev
```

`http://localhost:5173/pigeon/model-lab`에 접속해 일반 비둘기를 확인하고 이미지 파일 또는 외부 GLB를 선택합니다.

### 1단계 수용 기준
1. **형태**: 몸통과 목 연결, 머리 크기, 접힌 날개의 실루엣을 정면/측면/45°에서 검토
2. **디테일**: 목 광택, 잔깃, 홍채, 부리, 붉은 발의 식별 가능성
3. **체형**: 일반 비둘기와 닭둘기가 실제 비둘기 형태를 유지하면서 구분되는지
4. **기술**: 실제 GLB 렌더, 클립 재생, 리소스 누수·WebGL 오류 없이 모델 전환
5. **품질 차이 기록**: 시안에 미치지 못하는 항목을 외형/재질/리깅으로 구분

## 실행 검증 제약

GitHub 커넥터로 파일을 작성했지만, 현재 실행 환경에서는 GitHub 네트워크 주소 확인이 안 되어 저장소를 로컬에 클론하거나 설치·Vite 빌드·Playwright E2E를 실행하지 못했습니다. 이 코드는 **정적 작성 완료, 런타임 미검증 상태**입니다.

배포는 진행하지 않았으며 브랜치 및 PR로만 제공합니다. 검증 후 외형이 목표 시안에 미달하면 다음 단계(애니메이션·환경) 전에 외부 모델 또는 조형 자체를 개선해야 합니다.
