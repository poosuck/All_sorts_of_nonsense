# 비둘기 모델 수정 명세서 v1.0

작성일: 2026-10-28 · 상태: 구현 전 작업 기준

## 1. 목적과 기준 버전

사용자가 제공한 비둘기 참고 이미지의 **둥근 체형, 몸통과 연결되는 날개, 얇은 겹깃, 부위별 깃털 흐름**을 현재 3D 모델에 반영한다. 단순한 깃털 개수 증가나 표면 요철 강화가 목적이 아니다.

- 작업 브랜치: `codex/pigeon-stylized-reference`
- 수정 전 기준 커밋: `5901c7c`
- 대상: `/pigeon`의 일반 비둘기, kenchoo 기반 모델
- 비교 기준: 사용자가 이 대화에 제공한 이미지. 특정 실사 비둘기 일반론보다 사용자의 시각적 목표를 우선한다.
- 현재 상태 확인 이미지: `docs/pigeon/stylized-reference/side.png`, `front.png`
- 이번 범위: 체형, 날개 구조와 부착, 깃털 형상·방향·배열·재질, 꼬리·얼굴·발의 표현 통일.
- 조명·노출·배경·게임 기능·닭둘기 모델은 이번 수정 대상에서 제외한다. 검수용 카메라와 자세 설정은 허용한다.

이 문서는 다음 수정의 목표를 정의한다. 과거의 구현 기록인 `STYLIZED-REFERENCE.md`에 적힌 현재 방식을 그대로 유지해야 한다는 뜻은 아니다. 원본 라이선스 파일과 출처는 보존하되, 목표를 충족하기 위한 작업용 모델·토폴로지·리깅 수정 또는 재제작을 허용한다.

## 2. 참고 이미지의 역할

| 참고 이미지 | 주 검수 대상 | 해석 시 주의점 |
| --- | --- | --- |
| 옆에서 먹이를 쪼는 비둘기 | 몸통 타원, 날개 면적·경계, 덮깃 겹침, 두 줄의 검은 띠, 꼬리 | 머리 숙임과 몸통 비율을 분리한다. 이 자세를 중립 체형에 고정하지 않는다. |
| 날개를 펼친 비둘기 | 어깨 연결, 작은 덮깃부터 긴 비행깃까지의 크기 단계, 부채꼴 전개 | 접힌 날개 패치를 늘리는 것으로 대체하지 않는다. |
| 서 있는 비둘기 | 중립 자세의 머리·목·가슴 비율, 발 노출, 몸통의 중심 | 흐릿한 부분의 세부 깃털 모양은 추정해서 합격 기준으로 삼지 않는다. |
| 앞·위에서 먹는 비둘기 | 등과 양쪽 날개의 연결, 목 깃털 방향, 등·어깨 덮깃, 날개의 좌우 관계 | 원근에 따른 머리·몸통 크기 차이를 실제 비율로 복사하지 않는다. |

목표: 몸통은 통통한 달걀형, 날개는 어깨에서 뒤로 모이는 접힌 구조, 깃털은 얇은 층으로 읽힌다. 현재의 세로로 긴 배 모양 몸통, 아래로 늘어진 날개 패치, 볼록한 비늘 표현을 해소한다.

| 단계 | 우선순위 | 작업 | 다음 단계로 넘어가는 조건 |
| --- | --- | --- | --- |

| B | P0 | 날개 부착·접힘·뒤끝, 펼친 날개의 기본 구조 | 정면·측면·위쪽 사선·후면에서 날개가 옆가슴에 붙은 별도 판처럼 보이지 않는다. |
| C | P0 | 부위별 깃털 방향과 종류·크기 단계 | 요철 없이 방향 표시만 해도 어깨에서 날개 끝으로 흐름이 읽힌다. |

| E | P1 | 머리·목·가슴·배의 질감과 표현 통일 | 수평 비늘무늬, 점 노이즈, 부위별 재료 단절이 사라진다. |
| F | P1 | 꼬리·발·얼굴, 변형 및 최종 비교 | 모든 필수 시점·자세에서 구조·표면·동작 검수를 통과한다. |

앞 단계에서 명확한 차이가 남아 있으면 뒤 단계의 디테일 증가로 덮지 않는다. 구현자는 렌더링을 직접 비교하고 재수정한다. 일상적인 품질 판단을 사용자에게 반복해서 넘기지 않는다.

## 4. 체형 수정 요구사항

### BODY-01 — 몸통을 연결된 타원형으로 정리 [P0]

**현재 문제**

- 측면에서 앞가슴은 높고 크게 솟고, 뒤쪽 몸통은 길게 가늘어진다.
- 정면에서 배가 아래로 길어진 배 모양으로 읽힌다.
- 가슴·배 확대와 뒤쪽 몸통의 형태가 따로 조정되어 덩어리가 연결되지 않는다.

**수정**

- 등, 옆구리, 앞가슴, 아랫배를 하나의 몸통 볼륨으로 조정한다.
- 옆구리·엉덩이의 볼륨을 보강하고 몸통에서 꼬리로 급하게 가늘어지는 구간을 줄인다.
- 앞가슴의 가장 튀어나온 위치와 배의 최저점을 함께 조정한다. 아래 방향 확대만으로 통통함을 만들지 않는다.
- 몸통 축, 어깨 위치, 꼬리 기부를 함께 확인하면서 앞뒤 길이를 조정한다.
- 정면 너비만 늘려서 측면의 긴 삼각형을 남기지 않는다.

**합격 기준**

- 측면 실루엣에서 가슴·배·엉덩이가 끊김 없는 둥근 덩어리로 읽힌다.
- 정면에서 아래로 길게 처진 배나 날개 아래의 급격한 잘록함이 없다.
- 꼬리를 가리고 보아도 몸통 자체가 길고 뾰족한 삼각형으로 남지 않는다.
- 몸통을 둥글게 만들기 위해 발을 몸 안에 묻거나 지면 아래로 내리지 않는다.

### BODY-02 — 머리·목·어깨 연결 [P0]

- 작은 머리와 길고 가는 목의 인상을 완화한다. 둥근 머리와 짧고 두꺼운 목을 만든다.
- 목 아래를 가슴뿐 아니라 어깨·등까지 넓게 연결한다.
- 머리를 일괄 확대하여 눈·부리·납막이 함께 과대해지지 않도록 얼굴 요소의 비율을 별도로 확인한다.
- 먹는 자세에서 목·등의 곡선이 이어져야 한다. 머리 숙임을 중립 자세의 지오메트리에 고정하지 않는다.

**합격 기준:** 중립 자세에서 머리가 긴 목 끝에 얹힌 느낌이 없고, 먹는 자세에서 목과 등 사이가 접히거나 꺾여 보이지 않는다.

## 5. 날개 구조와 부착 요구사항

### WING-01 — 깃털보다 먼저 날개 전체 볼륨 재구성 [P0]

**현재 문제:** 타원 영역 안에 깃털을 투영한 패치가 있다. 접힌 날개의 어깨, 접힘, 뒤끝을 가진 독립적인 구조가 충분하지 않다.

**수정**

- 날개 기부는 목 뒤 어깨 부근에 둔다.
- 윗부분은 등의 흐름을 따르고, 넓은 중앙 면은 옆구리를 덮으며, 뒤쪽은 꼬리 방향으로 좁아지는 접힌 날개를 만든다.
- 날개 앞부분이 앞가슴을 침범하거나, 아랫부분이 배를 덮는 앞치마처럼 내려오지 않도록 위치·회전을 조정한다.
- 날개 기본 면과 몸통 표면 사이에 필요한 얇은 볼륨을 설계한다. 모든 지점을 몸통에 동일하게 밀착시키거나 동일한 거리로 띄우지 않는다.
- 가려지는 기존 날개 면과 새 날개 면의 소유 영역을 정리한다. 중복된 두 표면을 계속 띄워서 관통 문제를 해결하지 않는다.

### WING-02 — 경계별 연결 방식 [P0]

| 경계 | 필요한 구조 | 불합격 상태 |
| --- | --- | --- |
| 위: 등 ↔ 날개 | 작은 어깨 깃털이 큰 날개 덮깃의 뿌리를 가린다. | 날개 패치의 시작선·테두리가 등 위에 드러난다. |
| 앞: 목·가슴 ↔ 날개 | 짧은 전이 깃털로 연결하고 앞가슴은 남겨둔다. | 큰 날개깃 끝이 가슴 한가운데에 바로 놓인다. |
| 아래: 날개 ↔ 옆구리·배 | 얇은 날개 가장자리 아래로 작은 몸통 깃털이 이어진다. | 두꺼운 흰 조각이 배 옆에서 돌출된다. |
| 뒤: 날개 ↔ 꼬리 방향 | 긴 비행깃들이 모여 날개 뒤끝을 만든다. 꼬리와 구분된다. | 둥근 패치가 갑자기 끝나고 꼬리 판만 이어진다. |

**합격 기준**

- 정면에서 양쪽 날개가 흰 비늘 갑옷처럼 옆으로 튀어나오지 않는다.
- 측면에서 날개 주축이 아래보다 뒤쪽으로 이어진다.
- 위쪽 사선에서 등·어깨·양쪽 날개의 관계가 자연스럽다.
- 후면에서 좌우 날개 끝과 꼬리가 서로 구분된다.

### WING-03 — 접힘과 펼침의 일관성 [P0]

- 어깨, 접힌 중간 부분, 긴 비행깃의 배열을 구분한다.
- 펼친 상태에서 몸 가까운 짧은 깃털부터 바깥쪽의 긴 깃털까지 크기 단계가 이어진다.
- 긴 비행깃은 부채처럼 펼쳐지며 날개 끝 방향으로 정렬한다.
- 접힌 표면용 패치를 단순 확대·회전해 펼친 날개로 대신하지 않는다.
- 현재 리그·메시가 이 구조를 표현하지 못하면 작업용 날개 메시와 필요한 리그를 수정하거나 재제작한다. 버튼이 동작한다는 이유로 펼친 날개의 품질을 통과시키지 않는다.

**합격 기준:** 접기 → 펼치기 → 접기의 중간 자세에서 날개 기부가 분리되거나 깃털이 몸에 남거나, 긴 깃털이 서로 뒤집히지 않는다.

## 6. 깃털 방향·형상·겹침 요구사항

### FEATHER-01 — 부위별 방향장 설계 [P0]

| 부위 | 기준 흐름 | 필요한 변화 |
| --- | --- | --- |
| 머리 | 머리 곡면을 따르는 아주 짧은 깃털 | 목 패턴을 그대로 확대·축소하여 두르지 않는다. |
| 목 | 머리 아래에서 목·가슴 쪽으로 내려가는 조밀한 흐름 | 목 둘레를 가로로 감는 줄무늬가 우선해서 보이면 안 된다. |
| 가슴 | 목 아래에서 배로 부드럽게 내려감 | 중앙과 옆면의 곡면에 맞춰 방향이 바뀐다. |
| 옆구리 | 뒤·아래로 이어지는 흐름 | 날개 아래의 작은 깃털과 연결한다. |
| 어깨·윗덮깃 | 뒤쪽으로 눕고 퍼짐 | 뿌리가 드러나지 않으며 중앙의 큰 깃털로 전환된다. |
| 날개 중앙 | 뒤·바깥쪽으로 비스듬히 겹침 | 같은 방향으로 아래로 처지는 배열을 폐기한다. |
| 날개 뒤끝 | 길어지며 날개 끝으로 모임 | 중앙의 짧은 둥근 조각을 끝까지 반복하지 않는다. |
| 꼬리 | 꼬리 기부에서 뒤끝으로 펼쳐지는 흐름 | 몸통의 비늘 패턴을 이어서 적용하지 않는다. |

깃털의 방향은 날개·몸통의 해부학적 위치와 변형을 따라가야 한다. 월드 높이나 동일한 2D 격자만으로 모든 부위를 결정하지 않는다.

### FEATHER-02 — 날개깃 종류와 크기 단계 [P1]

- 작은 어깨 깃털 → 중간 덮깃 → 큰 덮깃 → 긴 비행깃의 계층을 만든다.
- 각 계층은 길이뿐 아니라 폭, 끝 모양, 겹침, 방향도 다르게 설계한다.
- 어깨에는 몸통 깃털과 날개깃 사이를 이어주는 중간 단계가 있어야 한다.
- 반복성을 줄이는 변화는 기준 방향과 계층을 유지한 상태에서 제한적으로 준다. 무작위 회전·크기로 구조를 흐리지 않는다.

### FEATHER-03 — 한 장의 단면과 보이는 부분 [P1]

**현재 문제:** 양끝이 좁은 잎 모양의 전체 면과 볼록한 중앙이 드러나 패딩·비늘처럼 보인다.

**수정**

- 뿌리는 윗깃에 가려지고 둥근 끝부분이 주로 보이도록 형상을 설계한다.
- 깃털 중앙은 완만하게 휘고 가장자리는 얇아진다.
- 깃털 끝은 둥글되, 둥근 구슬이나 독립된 부푼 덩어리가 되지 않게 한다.
- 깃대·깃가지 표현은 형태가 맞은 뒤 얕게 추가한다. 모든 깃털에 진한 중심선을 긋지 않는다.

**합격 기준:** 보이는 깃털의 대부분이 양끝이 드러난 잎 모양이 아니며, 측면에서 패딩 같은 두꺼운 단면이 보이지 않는다.

### FEATHER-04 — 얇은 층의 겹침 [P1]

- 입체감은 깃털 한 장의 큰 볼록함보다 여러 얇은 깃털의 높이 차에서 나오게 한다.
- 윗깃이 아랫깃의 뿌리를 가리도록 배치한다. 모든 깃털의 테두리를 완전히 노출하지 않는다.
- 열의 간격, 깃털 길이, 겹침 비율이 같은 구역 안에서 일관되게 이어지도록 한다.
- 이동·회전·변형 후에도 층 순서와 소속 부위가 유지되어야 한다.
- 관통·깜빡임 해결을 위해 날개 전체를 몸통에서 과도하게 띄우지 않는다.

**합격 기준:** 날개 전체의 매끈한 곡면과 개별 깃털 끝을 동시에 읽을 수 있다. 틈, 검은 구멍, 깨진 삼각형, 표면 깜빡임이 없다.

### FEATHER-05 — 검은 날개 띠 [P1]

- 날개를 가로지르는 두 띠가 명확히 보이게 한다.
- 깃털 배열과 접힘에 맞춰 띠의 위치·방향·폭을 정의한다.
- 개별 깃털 경계에서는 자연스럽게 조금 끊기되, 띠 전체의 폭과 간격은 안정적으로 이어진다.
- 얇은 톱니 선, 잘린 얼룩, 임의의 검은 깃털 열처럼 보이지 않게 한다.
- 체형 변화와 날개 접힘·펼침 중 색 영역이 다른 깃털로 미끄러지지 않도록 한다.

**합격 기준:** 일반 관찰 크기에서 먼저 두 띠가 읽히고, 확대하면 깃털별 경계가 보인다. 띠의 가장자리에 삼각형 모양의 파손이나 잔 노이즈가 없다.

## 7. 표면 질감 요구사항

### SURFACE-01 — 가슴·배 [P1]

- 현재의 일정한 수평 곡선·비늘 반복을 제거한다.
- 깃털 한 장의 전체 테두리가 아니라 일부 짧은 끝이 드러나게 한다.
- 가슴은 더 밀착되고, 배의 윤곽에서는 조금 풀어지는 차이를 만든다.
- 요철은 얕게 유지한다. 외곽선, 겹침, 미세한 결의 크기를 구분한다.
- 점 노이즈를 추가해서 깃털로 대신하지 않는다. 불규칙성에는 방향과 크기 범위가 있어야 한다.
- 먼 거리에서는 부드러운 표면으로, 가까이에서는 짧은 깃털 끝으로 읽혀야 한다.

**불합격 예:** 파충류 비늘, 수평 엠보싱 천, 솜뭉치, 전신에 같은 주파수의 노이즈.

### SURFACE-02 — 목 [P1]

- 몸통보다 작고 조밀하며 조금 더 길쭉한 깃털 끝을 표현한다.
- 청록·보라·회색을 깃털 단위로 분산한다. 높이로만 나눈 매끈한 색 띠를 줄인다.
- 목 아래 흐름을 따르고, 머리·가슴 경계에서 크기와 밀도가 점진적으로 바뀌게 한다.
- 광택 강도를 올려 디테일 부족을 가리지 않는다. 이번 검수는 고정된 조명에서 진행한다.

### SURFACE-03 — 머리·몸통·날개 표현 통일 [P1]

- 실사 머리, 비늘 몸통, 패딩 날개의 세 가지 재료처럼 분리되는 인상을 없앤다.
- 머리는 가장 미세하고 부드럽게, 몸통은 짧고 밀착되게, 날개는 큰 얇은 겹깃으로 구분한다.
- 세 부위의 가장자리 두께·곡률·색 변화·표면 거칠기 표현은 같은 스타일로 연결한다.
- 원본 텍스처의 구운 명암과 얼룩이 남아 스타일이 분리되는 부분은 정리한다.
- 눈·부리·납막에 몸통의 깃털 요철을 적용하지 않는다.

## 8. 꼬리·얼굴·발 요구사항

### DETAIL-01 — 꼬리 [P1]

- 길이를 줄이는 것과 별개로, 여러 장의 납작한 깃털과 둥근 끝을 구분한다.
- 두 갈래의 길고 뾰족한 판처럼 보이는 실루엣을 정리한다.
- 날개 뒤끝과 꼬리 기부를 구분하고, 펼침에서 깃털이 한 덩어리 판으로 늘어나지 않도록 한다.

### DETAIL-02 — 얼굴 [P1]

- 둥근 머리 위에서 눈, 주황 계열 홍채, 어두운 동공, 부리와 밝은 납막을 구분한다.
- 머리 비율을 바꾸더라도 눈이 묻히거나 튀어나오지 않도록 한다.
- 몸통 스타일에 맞춰 머리 텍스처를 정리하되 눈·부리 식별성을 유지한다.

### DETAIL-03 — 발 [P1]

- 목표의 짧고 도톰한 다리·발가락 인상에 맞춰 조정한다.
- 발가락 관절·가는 표면 주름·발톱은 구분하되, 각진 막대 조합처럼 과장하지 않는다.
- 몸통 수정 중 발을 고정하는 구현 제약과 발 자체를 수정하지 않는 디자인 제약을 혼동하지 않는다. 필요하면 발도 수정한다.
- 중립·걷기·먹기에서 지면 접촉과 지지 자세를 확인한다.

## 10. 비교·검수 절차

### 10.1 동일 조건 유지

- 수정 전 `5901c7c`와 수정 후를 같은 카메라·거리·해상도·시점·조명·노출·시간·체형 값으로 캡처한다.
- 목표 이미지와 비교할 때는 가능한 한 유사한 자세와 관찰 방향을 사용한다. 서로 다른 자세·원근의 차이는 모델 차이와 구분한다.
- 카메라 줌으로 모델 크기를 맞춘 뒤, 몸통·날개·머리 각각의 비율과 상대 위치를 확인한다. 구도가 달라 보이는 효과를 체형 개선으로 보고하지 않는다.
- 참고 이미지의 실제 치수를 측정하지 않았으므로 임의의 수치 비율을 정답으로 단정하지 않는다. 수치 목표를 도입할 경우 측정 기준과 정규화 방법을 함께 기록한다.

### 10.2 필수 시점·자세

| 캡처 | 필수 확인 |
| --- | --- |
| 중립 측면 | 몸통 타원, 목 길이, 날개 주축·면적·뒤끝, 꼬리 길이 |
| 중립 정면 | 몸통 너비·높이 균형, 날개 돌출, 가슴 비늘 반복, 머리·눈 |
| 중립 3/4 | 어깨 부착, 앞가슴과 날개 경계, 깃털 단면·겹침 |
| 위쪽 사선 | 등·어깨·양쪽 날개 연결, 깃털 방향과 크기 단계 |
| 후면 | 날개 뒤끝·꼬리 구분, 좌우 연결, 겹침 결함 |
| 먹기 측면·앞쪽 사선 | 참고의 먹는 자세와 비교, 목·등 곡선, 날개 이탈·관통 |
| 날개 펼침·중간 접힘 | 기부 연결, 긴 비행깃의 전개, 접힘 중 층 순서 |
| 가슴·목·날개 확대 | 부위별 깃털 크기·방향, 얇은 끝, 반복성·노이즈 |

필요한 자세를 현재 모델이 표현하지 못한다면 검수 불가로 기록하고 해당 구조·리그를 보완한다. 다른 자세의 캡처를 같은 자세의 검증이라고 표시하지 않는다.

### 10.3 단계별 시각 검사

1. **실루엣:** 깃털 무늬와 색을 배제하고 체형·날개 위치만 확인한다.
2. **단색 면:** 날개 부착, 두께, 접힘, 깃털 겹침을 확인한다.
3. **방향 표시:** 깃털 뿌리→끝의 흐름과 크기 계층을 확인한다.
4. **최종 재질:** 색·요철·검은 띠·목 질감이 같은 구조를 따르는지 확인한다.
5. **연속 동작:** 정지 화면 사이에서 관통·깜빡임·분리·색 미끄러짐이 없는지 확인한다.

확대 화면과 일반 관찰 크기를 모두 본다. 확대에서만 깃털로 읽히거나 멀리서만 결함이 숨겨지는 상태는 통과시키지 않는다.

### 10.4 구현자가 직접 반복 수정할 결함

- 날개가 몸통 옆의 별도 패치·갑옷·앞치마처럼 보임.
- 날개깃이 전부 아래로 처지거나 같은 크기로 반복됨.
- 깃털 뿌리와 전체 테두리가 모두 드러나 잎사귀·패딩처럼 보임.
- 몸통에 수평 비늘무늬, 점 노이즈, 과한 엠보싱이 보임.
- 검은 띠에 찢긴 삼각형·톱니 노이즈·얼룩이 보임.
- 머리·몸통·날개가 서로 다른 스타일의 재료로 읽힘.
- 정면에서 날개가 과도하게 튀어나오거나 측면에서 날개 뒤끝이 없음.
- 체형 값이나 자세가 바뀌면 깃털이 분리·관통하거나 제자리에 남음.

위 결함은 알려진 차이로만 적고 완료 처리하지 않는다. 원인을 수정하고 같은 조건으로 다시 렌더링한다.
