# 비둘기 새 모델 제작

[새 모델 제작·웹 렌더링 명세서 v1.0](MODEL-SPEC.ko.md)을 현재 작업 기준으로 사용합니다. 문서 작성 상태이며 새 모델은 아직 제작하지 않았습니다.

## 기존 렌더링 초기화

2026-10-29 사용자의 “비둘기 렌더링 전부 삭제, 처음부터 다시하자” 요청에 따라 기존 구현을 제거했습니다.

- 비둘기 렌더러, 모델, 텍스처, 리그, 동작, 깃털 생성 코드 제거
- 이전 GLB와 외부 모델, 모델 검증실, 생성·설치·캡처 스크립트 제거
- 과거 렌더링 이미지·영상·검증 기록과 구현 보고서 제거
- `/pigeon`과 홈의 진입 링크는 준비 화면으로 유지
- 기존 구현은 Git 이력으로만 확인 가능하며 현재 페이지에서 불러오지 않음

## 새 작업의 기준

기준은 사용자가 새로 제공한 **8방향·얼굴 확대·다양한 자세가 포함된 회색 비둘기 시트(R01)**입니다. 해당 이미지 파일은 저장소에 포함되어 있지 않습니다. 이전 먹이 먹는 비둘기 사진은 보조 자료이며 충돌 시 새 시트와 최신 명세서를 우선합니다.

체형과 비율, 몸통에 이어지는 날개 부착, 깃털의 겹침·방향·질감을 우선합니다. 1차 범위는 일반 비둘기 1개체·8방향·확대 검증·기본 자세 7종·웹 관찰 화면입니다. 조명은 후순위이며 연속 애니메이션·닭둘기·공원·게임 기능은 후속 범위입니다.

[원본 기능 명세](pigeon_feeding_spec_v1.0.md)는 향후 기능을 위한 참고 문서이며 현재 구현 상태를 뜻하지 않습니다. 새 모델의 외형과 1차 범위에는 [최신 모델 명세](MODEL-SPEC.ko.md)를 적용합니다.
