# 비둘기 작업 초기화

2026-10-29 사용자의 “비둘기 렌더링 전부 삭제, 처음부터 다시하자” 요청에 따라 기존 구현을 제거했습니다.

- 비둘기 렌더러, 모델, 텍스처, 리그, 동작, 깃털 생성 코드 제거
- 이전 GLB와 외부 모델, 모델 검증실, 생성·설치·캡처 스크립트 제거
- 과거 렌더링 이미지·영상·검증 기록과 구현 보고서 제거
- `/pigeon`과 홈의 진입 링크는 준비 화면으로 유지
- 기존 구현은 Git 이력으로만 확인 가능하며 현재 페이지에서 불러오지 않음

## 새 작업의 기준

기준은 대화에서 마지막으로 지정한, 고개를 숙여 모이를 먹는 **회색 비둘기 사진**입니다. 해당 사진 파일은 저장소에 포함되어 있지 않습니다.

체형과 비율, 몸통에 이어지는 날개 부착, 깃털의 겹침·방향·질감을 우선합니다. 조명은 후순위이며 닭둘기는 일반 비둘기 완성 이후 범위입니다. 이번 초기화에는 새 모델 제작을 포함하지 않습니다.

[원본 기능 명세](pigeon_feeding_spec_v1.0.md)는 향후 기능을 위한 참고 문서이며 현재 구현 상태를 뜻하지 않습니다.
