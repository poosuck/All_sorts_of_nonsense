## 현재 기준

사용자가 새로 제공한 8방향·얼굴 확대·다양한 자세의 회색 비둘기 시트(R01)를 우선합니다. 해당 이미지 파일은 저장소에 포함되어 있지 않아 비율은 초기 추정값으로 표시했습니다. 이전 먹이 먹는 비둘기 사진은 자세·겹깃의 보조 자료입니다.

몸통·목·머리가 이어지는 새 단면 로프트를 Blender에서 만들고 같은 형상을 GLB로 내보냅니다. 현재 웹 화면에서는 서기 1종, 8방향 카메라, 회전·확대·시점 초기화를 지원합니다.

## 범위와 이력

기존 비둘기 렌더러·자산·검증실은 2026-10-29 사용자 요청으로 제거했으며 새 화면에서 다시 불러오지 않습니다. 원본 이미지 파일 보관·픽셀 실측, 세밀한 얼굴, 겹깃·잔깃, 최종 색·목 광택, 리그·7종 자세는 아직 남아 있습니다. 닭둘기·공원·게임 기능과 연속 애니메이션은 후속 범위입니다.

[원본 기능 명세](pigeon_feeding_spec_v1.0.md)는 후속 게임 기능의 참고 문서입니다. 새 모델의 외형과 1차 범위는 최신 모델 명세를 따릅니다.
