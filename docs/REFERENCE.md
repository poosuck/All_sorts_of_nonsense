## 원본 보존과 이식 경로

원본 ZIP과 전체 추출본은 작업 공간에 보존했습니다. 배포 프로젝트 안에는 이식에 필요한 `app/page.tsx`, `app/globals.css`, `package.json`, 푸딩 관련 `lib/*.ts` 14개를 변경 없이 `vendor/pudding-v24/`에 보관했습니다. 파일별 해시는 해당 디렉터리의 `manifest.json`에 있습니다.

`source:sync`는 고정된 TypeScript 5.9.3으로 타입을 제거하고 상대 import에 `.js` 확장자를 붙입니다. 원본 CSS는 Tailwind/React 컴포넌트용 의존성을 제외한 앱 스타일을 `.pudding-page`로 한정합니다. 원본의 일시적인 전체 화면 도구 cursor 규칙은 그대로 유지합니다. 생성 파일 일치 여부는 `source:check`로 확인합니다.

화면은 제공된 `app/page.tsx`의 레이아웃·문구·순서·색상·상태 메시지·도구 그림을 Vue 템플릿으로 옮겼습니다. React/Radix 슬라이더·선택 버튼은 같은 색상/크기의 native 컨트롤로 연결했습니다. Lucide 아이콘은 원본과 같은 1.31.0 계열의 Vue 패키지를 사용합니다.

## 유지한 동작

- lathe 형상, 정점 변형 공식, 카메라, 조명·환경맵·바닥 그림자.
- 5가지 맛의 원본 재질, 300ms 전환, `pudding-flavor` 선택 저장.
- 물성 60/50 기본값, x/z/squash/dent 채널과 적분·감쇠·복원.
- 누르기·당기기·놓기, PC 화면 빈 곳에서 시작하는 휘두르기, 속도·접촉 방향에 따른 강도, raycast 및 중간 구간 스윕.
- 채찍 줄 시뮬레이션·실제 줄 접촉·재타격 latch·손 이동에 따른 whoosh·끝 속도에 따른 공기 파동.
- 포인터 캡처, 단일 접촉, pointer cancel/blur/scroll/visibility 정리.
- 리셋 시 맛·도구는 유지하고 물성·형상을 복원하는 동작.
- 원본 음원 4개, offset, 상대 gain, 손/양푼 6·휘두르기 3·채찍 충격 1 voice 정책.
- 원본 UI의 안내, 효과음 켜기/끄기, 선택적인 `document.modelContext` 설정·리셋 도구.

## 요청 범위 안에서 추가한 부분

- 별짓 홈 진열장, 푸딩 페이지에서 별짓 홈으로 돌아가는 링크.
- 전체 볼륨 슬라이더(기본 100%), compressor, 오디오 디코딩 오류 알림. 원본의 도구별 상대 gain과 충격음 타이밍은 유지합니다.
- Enter/Space 중앙 타격과 확인된 충격 콜백. 화면에 임의의 점수/카운터를 추가하지 않았습니다.
- WebGL 생성 실패 시 원본 채찍 overlay가 남지 않도록 생성 순서만 조정했습니다.
- 761–819px 화면에서 원본의 `min-width:820px`로 인한 가로 넘침을 막도록 컨테이너 최소 너비를 보정했습니다.

변경은 `scripts/sync-pudding-source.mjs`, Vue 래퍼, `controls.css`에서 확인할 수 있습니다. 원본 17개 파일 자체는 변경하지 않습니다.

- 1,000 step의 충격·누르기·복원 시나리오에서 원본 TS와 생성된 JS의 물성 채널과 변형 정점이 정확히 일치하는지 검사합니다.

## 초기 공개 리소스 접근과 현재 기준의 구분

소스 ZIP 제공 전에는 공개 배포 JS를 확인했습니다. 이후 제공된 v24 소스로 그 이식을 교체했으며, 현재 생성 코드의 기준은 ZIP의 파일입니다. Sites 편집 프로젝트 접근 도구가 없어도 제공된 소스로 진행할 수 있습니다.

기존 사이트의 초기 요청은 `CONNECT tunnel failed, response 403`으로 차단됐고, 필요한 도메인을 환경 설정 초안에 저장한 뒤 실제 GET의 HTTP 200 응답을 확인했습니다. 초안 저장을 실제 정책 적용·환경 게시와 혼동하지 않습니다. 기존 배포 사이트에는 GET 이외의 쓰기 작업이나 배포를 수행하지 않았습니다.
